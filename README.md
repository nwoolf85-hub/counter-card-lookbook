# Counter Card Lookbook (internal)

Private/unlisted lookbook of Woolf Provisions x RepRally counter-card sell sheets
(LIT, LFG, SuperFeels), designs A-L. Mobile-first; tap a card to zoom, heart favorites,
send picks by text/email. Not for public distribution; noindex + robots disallow.

Regenerate web images from masters in `RepRally/Deals/`:
`sips -Z 1080 -s format jpeg -s formatOptions 82 <BRAND>-Design-<L>.png --out images/<BRAND>-<L>.jpg`
